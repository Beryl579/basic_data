🛠️ Stack & Skema Data

Stack: HTML + Vanilla JS + Tailwind (CDN) + Chart.js. Tanpa build-step: satu file .html langsung jalan. localStorage berperan sebagai "backend". Grid custom dipilih karena Handsontable berlisensi non-komersial & Luckysheet berat — untuk prototipe, grid custom lebih ringan dan edukatif. Untuk produksi: React + TanStack/Handsontable + Recharts.
